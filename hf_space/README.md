# HuggingFace Space Skeleton

Space name suggestion: `balancehub-live-health-viewer`

## What it does
- Pulls `/system/health`
- Shows axis health, top volatility, SPOF, degree violations
- Links naturally to APO-NET Canon + BalanceHub runtime

## Run locally
```bash
cd hf_space
python -m pip install -r requirements.txt
python app.py
```
