# Growth Launch Plan (30 Days)

## Objective

Maximize: `Replicability × FreeFactor × Measurable Gravity`

## Success Metrics (Day 30)

- Stars >= 50
- Forks >= 10
- Docker pulls >= 100
- External contributors >= 2
- External deployments >= 5

## Week 1: Foundation + Measurement

- Day 1
  - Freeze runtime contract endpoints
  - Publish CI/CD checklist
- Day 2
  - Baseline KPI snapshot (stars/forks/clones/pulls)
  - Add public roadmap issue
- Day 3
  - Publish architecture diagram in README
- Day 4
  - Add screenshots: `/system/health`, `/system/economic-weight`
- Day 5
  - Create Docker Hub repo and push `latest`
- Day 6-7
  - Fork simulation on clean machine (<5 min target)
  - Fix friction blockers

## Week 2: Distribution Burst

- Publish launch post to:
  - HackerNews
  - Reddit `r/devops`
  - Reddit `r/selfhosted`
  - Reddit `r/microservices`
- Track click-through and clone/fork deltas every 24h
- Reply to comments with setup guide and dashboard screenshots

## Week 3: Replication Hardening

- Open 3 good-first-issues
- Add contributor quickstart
- Run weekly bug bash with external users
- Publish "Known Constraints" and "No Secrets Needed" section

## Week 4: Governance + Conversion

- Compare KPI against month targets
- Identify top 3 friction points from issues/comments
- Patch onboarding and rerun fork simulation
- Prepare Month-2 plan

## Daily Operating Cadence (15 min)

- Check GitHub traffic views/clones
- Check stars/forks/watchers
- Check `/system/health` drift and SPOF flags
- Log KPI to weekly report issue

## Kill Criteria

- If forks remain 0 for 14 days:
  - simplify README again
  - publish new HN/Reddit angle with clearer value proposition
